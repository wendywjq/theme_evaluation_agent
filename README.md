# 主题卡评测 Agent

本地单用户工作台。提交实际卡面和落地套餐后，可以核对卡面承诺、查看冲突套餐、定位生产环节、修改长标题并在相同供给快照上复评。首页附有一张可直接操作的合成午餐卡。

## 启动

需要 Python 3.9+。默认模式使用 Python 标准库、SQLite 和浏览器原生模块。

```sh
git clone https://github.com/wendywjq/theme_evaluation_agent.git
cd theme_evaluation_agent
python3 app.py
```

打开 [本地工作台](http://127.0.0.1:8776/)。可用 `python3 app.py --port 8780` 更换端口。记录保存在仓库下的 `.data/workbench.db`，重启后可继续复核。设置 `QC_DATA_DIR` 可指定独立的数据目录。

## 三分钟走通示例

1. 打开「问题归因」。示例卡承诺“20元以内”，60 个可用单人午餐套餐中有 42 个支持、18 个冲突。点击「查看冲突套餐」可核对价格、城市、套餐 ID 和展示位置。
2. 点击「核对生产记录」。本例的生成输入写明符合条件的数量，原稿却把价格描述为整卡承诺，所以问题定位到文案生成。其他证据组合会定位为素材组装、主题与供给组装、渲染或待补材料。
3. 点击「修改长标题并复评」，将新版展示长标题与新版原稿改成「工作日午餐，单人套餐随心选」。保存后进入 V1 → V2 对比，原价格问题显示为已解决，可检查其他分项有无退化。
4. 使用版本下拉框回看 V1。打开最新版本的「分项评测 → 复核」可填写人工结论和依据；「输入与生产记录」保留改判记录。V2 的视觉及表达质量可以独立复核。

## 导入自己的卡片

选择「新建评测」。填写主题及用户可见的标题，可上传实际渲染图（PNG、JPEG、WebP，最大 3 MiB）。未上传时显示本地午餐示意模板。上传图在本地模式使用填写的转录；遗漏转录会进入待复核。

供给可粘贴 JSON 数组或选择 UTF-8 CSV / JSON 文件。每行代表快照中**当时可用**的一个套餐，文件顺序即落地页展示顺序。套餐 ID 必须唯一。同一快照支持 1–2000 个套餐。价格为每份套餐的实际价格；数值、城市或布尔字段缺失时留空。CSV 支持下列表头，亦可使用 `id,name,city,price,people,lunch,weekday`。

```csv
套餐ID,名称,城市,价格,人数,午餐,工作日
TEST-001,菌菇饭,示例城,18,1,是,是
TEST-002,番茄牛肉饭,示例城,25,1,是,是
```

生成输入和原稿是可选证据。缺少时展示已确认的卡面问题、待补材料与待验证归因。复评时锁定主题、快照、图片、标准及评测器；首版开放图外长标题和对应原稿的成对修改。变更供给或图片时，请创建独立评测。

## 两种评测模式

- **本地核验**先读取展示文案，再检查价格上限、人数、工作日与午餐条件，生成支持/冲突/未知明细。同时执行试点字数、上传图片尺寸和城市供给量规则。词句含限定或无法可靠解释时需要人工核验。吸引力、视觉质量等主观项默认交给人工。规则是公开午餐试点的有限实现。
- **可选视觉模型**适用于已配置支持图片输入与结构化文本输出服务的环境。选择此模式后，第一步只提交实际卡面和展示长标题，生成卡面转录和用户预期；第二步结合主题、卡面及字段核验计数给出分项评分建议。模型输出按检查项、分值范围和状态验证。缺少可用证据的条目进入待复核。供给原始表、API 密钥存放于本机；凭证只用于服务端请求已配置的模型端点。

启动服务前设置环境变量。`QC_MODEL_URL` 为完整的 chat-completions 端点，`QC_MODEL` 为服务支持的视觉模型版本，`QC_MODEL_KEY` 为可选服务端凭证。URL 仅支持 HTTPS 或本机 HTTP。配置后仍需在新建评测时主动选择视觉模式。真实模型的评分需用人工样本校准。

## 结果与复评

单卡报告包括主题场景、图内短标题、图外长标题、图片四个对象；展示各自适用的分值上限。底线命中、已核实的问题和待复核项单独记录。“待修改问题”按问题计数，“冲突供给”按套餐 ID 去重。复评保留各版原句、核验明细、机器原判、人工依据及时间。结果对比展示已解决、仍存在、新增和待复核四类变化。SQLite 事务和版本检查防止并发编辑覆盖已有结果。

## 验证

```sh
python3 -m unittest discover -s tests -v
```

核心实现位于 `evaluator.py`（承诺核验、归因和差异）、`app.py`（本地服务与持久化）、`vision.py`（可选视觉评测）、`web/`（工作台）。仓库只包含合成样例，不含企业数据、账号或平台接口。
